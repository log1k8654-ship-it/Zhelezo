# Железный дневник

Дневник силовых тренировок для телефона (iPhone и Android), который работает без интернета.

- Подходы, веса и повторы, рекорды, графики прогресса, цель недели.
- Программа тренера из фото, скриншота, PDF, Word, Excel или текста: распознаётся прямо на телефоне.
- Калории, вода за день, самочувствие после тренировки, вес тела.

## Установка

iPhone:
1. Откройте ссылку на сайт в Safari.
2. Нажмите «Поделиться» и выберите «На экран „Домой“».

Android:
1. Откройте ссылку на сайт в Chrome.
2. Нажмите меню ⋮ и выберите «Установить приложение» или «Добавить на главный экран».

Потом откройте дневник со значка один раз с интернетом: он сохранится на телефоне целиком (около 17 МБ). Дальше интернет не нужен.

Тренировки хранятся только на телефоне. Раз в неделю сохраняйте резервную копию: «Ещё» → «Сохранить».

## Для разработчика

`index.html` — всё приложение, `sw.js` — офлайн-кэш, `vendor/` — pdf.js, mammoth, SheetJS и Tesseract.js с данными для русского и английского.
